# CLAUDE

Regla canónica del repositorio para Codex y para cualquier flujo de GitHub:

1. Antes de empezar una tarea nueva, leer este archivo completo.
2. Si la tarea contradice esta memoria, detenerse y pedir confirmación.
3. Si el trabajo cambia una regla estable, actualizar este archivo en el mismo cambio.
4. No crear reglas paralelas en otros documentos sin enlazar o sincronizar esta memoria.
5. Si existe conflicto entre una instrucción puntual y esta memoria, prevalece la instrucción puntual para esa tarea, pero la memoria debe quedar actualizada si el cambio es permanente.

Uso práctico:

- Esta memoria es la referencia corta para decisiones recurrentes.
- La gobernanza amplia sigue viviendo en `docs/governance.md` y en los gates de CI.
- En PRs, revisar siempre este archivo antes de avanzar al siguiente cambio.
